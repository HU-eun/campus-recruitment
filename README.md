# 校招信息汇总平台

2027届校招/实习信息汇总平台，包含4900+条岗位数据、专业就业参考、招聘平台导航、求职管理系统等功能。

## 功能特性

- 🏠 **校招广场**：4900+条岗位，支持按批次、地点、行业、企业性质筛选
- 🔗 **平台导航**：官方平台、央企、地方人社局、综合平台分类汇总
- 🎓 **专业参考**：93个专业类的就业方向和前景
- 📄 **我的简历**：简历模板，分模块复制
- 🎯 **目标公司**：冲刺/稳妥/保底分类管理
- 📮 **投递追踪**：状态实时更新，支持导出Excel
- 🎤 **面试复盘**：模板化记录每次面试
- 📊 **统计仪表盘**：投递漏斗、转化率可视化
- ⏰ **节点提醒**：自动汇总截止和面试时间
- 🔄 **自动更新**：每天自动从飞书多维表格拉取最新数据

## 技术栈

- 纯前端：HTML + CSS + JavaScript（Tailwind CSS）
- 数据存储：浏览器 localStorage
- 自动更新：GitHub Actions + 飞书开放平台 API
- 部署：GitHub Pages

## 自动更新配置

本项目通过 GitHub Actions 每天自动从飞书多维表格拉取最新数据。

### 配置步骤

1. 在飞书开放平台创建企业自建应用，开通 `bitable:app` 权限并发布
2. 在 GitHub 仓库 → Settings → Secrets and variables → Actions 中添加：
   - `LARK_APP_ID`：飞书应用 App ID
   - `LARK_APP_SECRET`：飞书应用 App Secret
   - `BASE_TOKEN`：飞书多维表格 token
3. 配置完成后，每天自动更新数据

## 本地运行

直接用浏览器打开 `index.html` 即可使用。

## 数据备份

用户的投递记录、面试复盘等数据存储在浏览器本地，建议定期在「数据管理」页导出备份。
